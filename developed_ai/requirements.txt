# CPU-only torch: this service always runs on CPU (Stage 1's DeBERTa
# classifier is the only local inference; Stage 2 is the NVIDIA-hosted API).
# Without this, pip pulls the default PyPI build, which bundles CUDA
# runtime libs that are dead weight (and a much bigger, slower download) on
# a GPU-less box. A "+cpu" local version (e.g. 2.6.0+cpu) sorts higher than
# the plain version per PEP 440, so pip prefers it over the PyPI build once
# this index is available, without needing to hand-pin an exact version.
--extra-index-url https://download.pytorch.org/whl/cpu
